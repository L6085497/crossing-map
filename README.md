# crossing-map
Prototype map of train crossings in Waycross, GA.

- `index.html` – mobile-friendly Leaflet + OpenStreetMap map of 77 public at-grade crossings in Ware County, GA (FRA crossing inventory). Tap a crossing for details and Blocked/Clear buttons; reports are saved in your browser only (shared backend coming next). Top 5 launch crossings are ringed in orange.
- `ware_crossings.csv` / `ware_crossings.geojson` – cleaned FRA data (crossing ID, street, lat/lon, trains/day, AADT, railroad).

Data: FRA Crossing Inventory (Form 71) – Current, data.transportation.gov.
